# WhereIs Login Minimal Brand Design

## Goal

ปรับหน้า `/login` ให้ดูเป็นมิตร ใช้งานง่าย และสร้างภาพจำของ WhereIs โดยคงความ minimal ไม่ใส่รายละเอียดหรือภาพประกอบที่ไม่จำเป็น

## Visual direction

- ใช้โลโก้ไอคอนหมุดตำแหน่งแบบเส้นเดียวคู่กับชื่อ `WhereIs`
- ใช้โทนฟ้าอมเขียวเป็นสีหลัก และพื้นหลังขาวหรือฟ้าอมเทาอ่อน
- ใช้รูปทรงเรียบง่าย ไม่มี gradient หรือเอฟเฟกต์ตกแต่งมากเกินไป
- โลโก้ต้องยังอ่านรู้เรื่องเมื่อย่อเป็น favicon หรือไอคอน sidebar

## Login layout

- จัดฟอร์มให้อยู่ในพื้นที่ที่โฟกัสได้ชัดเจน
- แสดงโลโก้ด้านบน ตามด้วยข้อความ “ยินดีต้อนรับกลับมา” และคำอธิบายสั้น ๆ
- มีช่อง Email และ Password ที่แตะง่ายและรองรับ autocomplete
- มีลิงก์ “ลืมรหัสผ่าน” ใกล้ช่อง Password
- ใช้ “เข้าสู่ระบบ” เป็น action หลักเพียงปุ่มเดียว
- แสดง “ยังไม่มีบัญชี? สมัครสมาชิก” เป็น action รอง ไม่ให้ดูเป็นปุ่มหลักอีกปุ่ม
- ไม่ใช้ภาพประกอบขนาดใหญ่หรือข้อมูลที่ไม่เกี่ยวกับการเข้าสู่ระบบ

## Responsive and accessibility standards

- บนมือถือ ฟอร์มต้องแสดงครบโดยไม่ต้องเลื่อนมากเกินไป และปุ่มต้องไม่ถูกแป้นพิมพ์บัง
- รักษา contrast ของข้อความ ปุ่ม และ focus state ให้ชัดเจน
- ไอคอนแสดง/ซ่อนรหัสผ่านต้องมี accessible label
- แสดง validation error ใกล้ช่องที่ผิด พร้อมข้อความที่บอกวิธีแก้
- รองรับการส่งฟอร์มด้วยแป้นพิมพ์และลำดับ focus ที่เป็นธรรมชาติ

## Scope

การดำเนินการถัดไปจะเน้นหน้า `/login` และองค์ประกอบแบรนด์ที่จำเป็นต่อหน้านี้เท่านั้น ยังไม่รวมการเปลี่ยน design system ทั้งแอปหรือการเพิ่ม authentication flow ใหม่
